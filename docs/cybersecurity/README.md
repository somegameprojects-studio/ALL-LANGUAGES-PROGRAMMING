# คู่มือ Cybersecurity สำหรับผู้เริ่มต้น

อ่านตามลำดับได้เลย ไม่ต้องรีบจำทุกอย่าง

1. **พื้นฐานความปลอดภัยไซเบอร์** — ความลับ ความถูกต้อง และความพร้อมใช้งานของข้อมูล
2. **เครือข่าย** — IP, DNS, HTTP/HTTPS, Client และ Server
3. **บัญชีและตัวตน** — รหัสผ่าน MFA และสิทธิ์การเข้าถึง
4. **ภัยออนไลน์** — Phishing, Malware และ Social Engineering
5. **ความปลอดภัยเว็บ** — การตรวจข้อมูล การจัดการ session และการอัปเดต
6. **DDoS** — เข้าใจผลกระทบและการป้องกัน
7. **Incident Response** — แจ้งเหตุ เก็บหลักฐาน และกู้คืนระบบ

## หลักคิดสำคัญ
- ป้องกันก่อนเกิดเหตุ
- ให้สิทธิ์เท่าที่จำเป็น
- อัปเดตและสำรองข้อมูล
- เก็บ log อย่างเหมาะสม
- ทดสอบเฉพาะระบบที่ได้รับอนุญาต

## คำศัพท์สั้น ๆ
- **Threat:** สิ่งที่อาจก่อให้เกิดความเสียหาย
- **Vulnerability:** จุดอ่อนของระบบ
- **Risk:** ความเสี่ยงที่เกิดจากโอกาสและผลกระทบ
- **Mitigation:** วิธีลดความเสี่ยง
- **Incident:** เหตุการณ์ด้านความปลอดภัยที่ต้องตรวจสอบ
