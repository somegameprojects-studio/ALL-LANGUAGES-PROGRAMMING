# Phishing, Malware และความปลอดภัยส่วนบุคคล

## Phishing
มิจฉาชีพอาจปลอมชื่อองค์กร ส่งข้อความเร่งด่วน หรือสร้างหน้าเข้าสู่ระบบเลียนแบบ อย่ากดลิงก์เพราะความตกใจ ให้เปิดแอปหรือเว็บไซต์จากช่องทางที่รู้จักเอง

## Malware
ซอฟต์แวร์อันตรายอาจขโมยข้อมูล รบกวนเครื่อง หรือทำให้ไฟล์เข้าใช้งานไม่ได้ ลดความเสี่ยงด้วยการอัปเดต ติดตั้งซอฟต์แวร์จากแหล่งเชื่อถือได้ และสำรองข้อมูล

## ปกป้องบัญชี
- ใช้รหัสผ่านไม่ซ้ำกัน
- เปิด MFA
- ไม่แชร์ OTP หรือ recovery code
- ตรวจสอบอุปกรณ์ที่ล็อกอิน
- ออกจากระบบบนอุปกรณ์ที่ไม่ใช่ของตัวเอง
- ระวังข้อมูลส่วนตัวในภาพและเอกสารที่แชร์
