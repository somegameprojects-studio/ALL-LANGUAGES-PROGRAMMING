# พื้นฐานความปลอดภัยเว็บไซต์

## เช็กลิสต์
- ใช้ HTTPS และตั้งค่า cookie ให้เหมาะสม
- ตรวจสอบข้อมูลจากผู้ใช้ทั้งฝั่ง client และ server
- ตรวจสิทธิ์ทุกครั้งก่อนให้เข้าถึงข้อมูล
- ใช้ parameterized queries เมื่อติดต่อฐานข้อมูล
- เก็บรหัสผ่านด้วย password hashing ที่ออกแบบมาสำหรับรหัสผ่าน
- เก็บ secret ในระบบจัดการความลับ ไม่ฝังไว้ใน frontend หรือ Git
- อัปเดต framework และ dependencies
- สำรองข้อมูลและทดสอบการกู้คืน
- เก็บ log โดยไม่บันทึกรหัสผ่าน token หรือข้อมูลอ่อนไหวเกินจำเป็น

## จำไว้
HTTPS ช่วยป้องกันข้อมูลระหว่างทาง แต่ไม่ได้รับประกันว่าแอปปลอดภัย ต้องดูแลการยืนยันตัวตน การกำหนดสิทธิ์ และการจัดการข้อมูลด้วย
