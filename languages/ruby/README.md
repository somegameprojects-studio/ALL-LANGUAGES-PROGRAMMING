## Suggested learning path

1. Install the official toolchain or choose a suitable learning environment.
2. Learn basic syntax, values, variables, and expressions.
3. Practice control flow, functions, and data structures.
4. Explore modules, packages, libraries, and common tooling.
5. Build a small project and document how to run it.

## Content structure

- `basics/` — foundational concepts.
- `examples/` — small runnable programs.
- `tutorials/` — guided lessons.
