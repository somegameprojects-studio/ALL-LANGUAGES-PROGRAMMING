# Language Guide Starter

This directory is reserved for this language's learning materials.

## Planned content

- Overview and common use cases
- Installation and setup
- Syntax fundamentals, values, variables, and operators
- Control flow, functions, and data structures
- Modules, packages, libraries, and tooling
- Beginner-to-intermediate examples
- Small practical projects
- Official documentation and learning resources

## Contribution standards

1. Use official documentation as the primary reference.
2. State the compiler, interpreter, runtime, or specification version.
3. Include complete run instructions and expected output for examples.
4. Test code before marking it as verified.
5. Keep examples focused and explain important concepts.
6. Never include secrets, credentials, or private data.

Add detailed lessons and runnable samples in this directory as they are developed.
