# คู่มือภาษา C ภาษาไทย

C เป็นภาษาโปรแกรมแบบคอมไพล์ที่ให้การควบคุมการทำงานระดับต่ำ เหมาะกับการเรียนพื้นฐานระบบปฏิบัติการ ไมโครคอนโทรลเลอร์ และซอฟต์แวร์ประสิทธิภาพสูง

## 1. โปรแกรมแรก

บันทึกเป็น `main.c`

```c
#include <stdio.h>

int main(void) {
    printf("Hello, World!\\n");
    return 0;
}
```

- `#include <stdio.h>` เรียกใช้ส่วนประกาศฟังก์ชันรับ/ส่งข้อมูลมาตรฐาน
- `main` คือจุดเริ่มต้นของโปรแกรม
- `printf` แสดงข้อความ
- `return 0` แจ้งว่าจบการทำงานปกติ

## 2. คอมไพล์และรัน

ติดตั้ง compiler เช่น GCC หรือ Clang จากแหล่งที่เชื่อถือได้ แล้วใช้ `gcc main.c -o main` จากนั้นรันไฟล์ที่สร้างขึ้น (บน Windows อาจเป็น `main.exe`)

## 3. ตัวแปรและเงื่อนไข

```c
int score = 75;
if (score >= 50) {
    printf("ผ่าน\\n");
} else {
    printf("ลองใหม่\\n");
}
```

## 4. ลูปและฟังก์ชัน

```c
int add(int a, int b) {
    return a + b;
}

int main(void) {
    for (int i = 1; i <= 3; i++) printf("%d\\n", i);
    printf("%d\\n", add(2, 3));
    return 0;
}
```

## 5. จุดที่ต้องระวัง

C ต้องจัดการชนิดข้อมูลและหน่วยความจำอย่างรอบคอบ ตรวจขอบเขตอาร์เรย์และตรวจค่าที่รับเข้ามาเสมอ

## แบบฝึกหัด

1. รับจำนวนเต็มสองจำนวนแล้วบวกกัน
2. ตรวจว่าเลขเป็นคู่หรือคี่
3. เขียนฟังก์ชันหาค่าสูงสุดของเลขสองจำนวน
