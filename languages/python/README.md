# คู่มือภาษาและเทคโนโลยีในโฟลเดอร์นี้

เอกสารนี้เป็นจุดเริ่มต้นสำหรับเรียนรู้หัวข้อที่ระบุจากชื่อโฟลเดอร์ อ่านช้า ๆ ได้เลย ไม่จำเป็นต้องมีพื้นฐานมาก่อน

## 1. สิ่งนี้คืออะไร?

ภาษาโปรแกรมหรือเครื่องมือแต่ละชนิดถูกสร้างมาเพื่อแก้ปัญหาคนละแบบ บางอย่างใช้เขียนโปรแกรม บางอย่างใช้ค้นหาข้อมูล บางอย่างใช้กำหนดหน้าตาเว็บไซต์ และบางอย่างใช้เก็บค่าตั้งค่าของระบบ

ก่อนเริ่ม ให้จำไว้ว่า **เครื่องมือแต่ละชนิดมีหน้าที่ไม่เหมือนกัน** อย่าคาดหวังว่าทุกอย่างจะมีคำสั่ง `print` หรือทำงานแบบเดียวกัน

## 2. วิธีทำงานตั้งแต่ต้นจนจบ

ภาพรวมที่ใช้ทำความเข้าใจได้กับเครื่องมือส่วนใหญ่:

1. **เตรียมไฟล์** — สร้างไฟล์ให้ตรงกับชนิดของภาษา/เครื่องมือ
2. **เขียนคำสั่งหรือข้อมูล** — ทำตามกติกาของภาษานั้น เช่น การใช้วงเล็บ เครื่องหมาย และการเยื้องบรรทัด
3. **ส่งให้เครื่องมืออ่าน** — เปิดไฟล์ด้วยโปรแกรมที่รองรับ
4. **ตรวจความถูกต้อง** — เครื่องมือเช็กว่ารูปแบบและคำสั่งถูกต้องหรือไม่
5. **ประมวลผล** — บางภาษาคอมไพล์เป็นโปรแกรมก่อน บางภาษามีตัวแปลอ่านคำสั่งขณะทำงาน ส่วนไฟล์ข้อมูลจะถูกโปรแกรมอื่นอ่านไปใช้
6. **ดูผลลัพธ์** — ตรวจว่าผลที่ได้ตรงกับสิ่งที่ต้องการหรือไม่
7. **แก้ไขและทดลองใหม่** — อ่านข้อผิดพลาด แก้ทีละจุด แล้วลองอีกครั้ง

### คำว่า “คอมไพล์” คืออะไร?

ลองนึกถึงการแปลหนังสือจากภาษาหนึ่งไปเป็นอีกภาษาหนึ่ง คอมไพเลอร์ทำหน้าที่แปลงโค้ดต้นฉบับให้อยู่ในรูปแบบที่เครื่องมือหรือคอมพิวเตอร์นำไปทำงานต่อได้ บางภาษาไม่ต้องสั่งคอมไพล์เองทุกครั้ง เพราะเครื่องมือจัดการให้

### คำว่า “ตัวแปลภาษา” คืออะไร?

ตัวแปลภาษาคือโปรแกรมที่อ่านคำสั่งของภาษา แล้วประมวลผลตามกติกา บางตัวทำงานทีละคำสั่ง บางตัวแปลงเป็นรูปแบบกลางก่อน จึงไม่ควรเหมารวมว่าทุกภาษาทำงานเหมือนกัน

## 3. เตรียมตัวก่อนเขียน

1. ตรวจดูว่าเครื่องมือมีรุ่นใดและรองรับระบบปฏิบัติการของเราหรือไม่
2. ดาวน์โหลดจากเว็บไซต์ทางการหรือแหล่งที่โครงการแนะนำ
3. ติดตั้งตามคู่มือของผู้พัฒนา
4. เปิดโปรแกรมแก้ไขโค้ดหรือเทอร์มินัล
5. ตรวจว่าติดตั้งสำเร็จด้วยคำสั่งตรวจรุ่นที่เอกสารทางการระบุ

อย่าดาวน์โหลดไฟล์ติดตั้งจากเว็บที่ไม่น่าเชื่อถือ และอย่ารันคำสั่งที่ไม่เข้าใจโดยไม่ตรวจสอบก่อน

## 4. แนวคิดพื้นฐานที่ควรรู้

- **ข้อมูล:** สิ่งที่โปรแกรมนำไปใช้ เช่น ตัวเลข ข้อความ หรือค่าจริง/เท็จ
- **ตัวแปร:** กล่องเก็บข้อมูลที่มีชื่อเรียก
- **ชนิดข้อมูล:** บอกว่าข้อมูลเป็นตัวเลข ข้อความ หรือชนิดอื่น
- **ตัวดำเนินการ:** เครื่องหมายสำหรับคำนวณหรือเปรียบเทียบ
- **เงื่อนไข:** เลือกทำงานตามสถานการณ์
- **การทำซ้ำ:** สั่งให้ทำงานเดิมหลายรอบ
- **ฟังก์ชัน:** รวมคำสั่งเป็นชุดเพื่อเรียกใช้ซ้ำ
- **ข้อผิดพลาด:** สิ่งที่ทำให้โปรแกรมทำงานไม่ได้หรือได้ผลไม่ตรงที่คิด

รูปแบบการเขียนจริงของแต่ละภาษาอาจต่างกัน ให้ดูตัวอย่างเฉพาะภาษานั้นประกอบเสมอ

## 5. วิธีฝึกให้เข้าใจ

1. เริ่มจากตัวอย่างสั้น ๆ เพียงหนึ่งเรื่อง
2. พิมพ์โค้ดเองเพื่อให้คุ้นกับรูปแบบ
3. รันแล้วจดผลลัพธ์ที่เห็น
4. เปลี่ยนค่าหรือข้อความเพียงจุดเดียว
5. รันใหม่และสังเกตความแตกต่าง
6. ลองอธิบายด้วยคำของตัวเองว่าแต่ละบรรทัดทำอะไร

ตัวอย่างหลายภาษาพร้อมคำอธิบายอยู่ที่ [ตัวอย่าง Hello, World!](../../examples/hello-world/README.md)

## 6. ข้อผิดพลาดที่พบได้บ่อย

- สะกดชื่อคำสั่งไม่ถูก
- ลืมปิดวงเล็บ เครื่องหมายคำพูด หรือแท็ก
- ใช้เครื่องมือไม่ตรงกับชนิดไฟล์
- ยังไม่ได้ติดตั้ง runtime หรือ compiler
- เปิดไฟล์ผิดโฟลเดอร์
- ใช้ตัวอย่างจากเครื่องมือคนละรุ่น

เมื่อเกิดข้อผิดพลาด อย่าเพิ่งลบทุกอย่างทิ้ง ให้อ่านข้อความแจ้งเตือน ตรวจบรรทัดที่ระบุ แล้วแก้ทีละจุด

## 7. เส้นทางการเรียน

- ระดับเริ่มต้น: รู้จักเครื่องมือและทดลองตัวอย่างแรก
- ระดับพื้นฐาน: เข้าใจข้อมูล ตัวแปร และคำสั่งสำคัญ
- ระดับกลาง: แบ่งงานเป็นฟังก์ชัน จัดการข้อมูล และตรวจข้อผิดพลาด
- ระดับลงมือทำ: สร้างโปรเจกต์เล็ก ๆ และอธิบายวิธีใช้งาน
- ระดับต่อยอด: อ่านเอกสารทางการ ทดลองเครื่องมือเสริม และปรับปรุงผลงาน

## 8. ข้อควรจำ

คู่มือนี้เป็นพื้นฐานสำหรับเริ่มเรียน รายละเอียดการติดตั้ง ไวยากรณ์ และคำสั่งเฉพาะต้องตรวจจากเอกสารทางการของภาษาหรือเครื่องมือที่กำลังเรียนอยู่เสมอ
