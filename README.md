# CodeAtlas TH — คลังเรียนรู้ภาษาโปรแกรมภาษาไทย

เว็บไซต์เรียนรู้ภาษาโปรแกรมและเทคโนโลยี พร้อมคู่มือ ตัวอย่าง แบบฝึกหัด และโปรเจกต์สำหรับผู้เริ่มต้น

## เปิดเว็บไซต์

GitHub Pages จะเผยแพร่จาก branch `main` ผ่าน GitHub Actions เมื่อมีการ push การตั้งค่า workflow อยู่ที่ [pages.yml](.github/workflows/pages.yml)

> หากเป็นการเผยแพร่ครั้งแรก ให้ตรวจ Settings → Pages ว่า Build and deployment ใช้ GitHub Actions และรอ workflow ทำงานสำเร็จ

## ฟีเจอร์เว็บไซต์

- ค้นหาและกรองคู่มือภาษา/เครื่องมือ
- อ่านเส้นทางเรียนพื้นฐาน 10 ขั้น
- ทดลอง JavaScript ใน sandbox บนเบราว์เซอร์
- Code Visualizer ดูค่าตัวแปรทีละขั้น
- Skill Tree บันทึกความคืบหน้าในเบราว์เซอร์
- API Lab เรียนรู้ Request / Response / JSON ด้วยข้อมูลจำลอง
- Coding Challenge พร้อมตรวจรูปแบบคำตอบ
- แบบฝึกหัดพร้อมแนวคำตอบ
- ไอเดียโปรเจกต์ฝึกทำ
- พจนานุกรมคำศัพท์และแผนผัง Repository

## โครงสร้าง

| โฟลเดอร์ / ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | เว็บไซต์ CodeAtlas TH |
| `languages/` | คู่มือแยกตามภาษาและเทคโนโลยี |
| `language-examples/` | ไฟล์ซอร์สโค้ดจริงสำหรับ GitHub Linguist |
| `examples/` | ตัวอย่างการใช้งานรวม |
| `tutorials/` | บทเรียนแบบเป็นขั้นตอน |
| `projects/` | โครงงานฝึกทำ |
| `resources/` | แหล่งเรียนรู้เพิ่มเติม |
| `.github/workflows/pages.yml` | เผยแพร่เว็บไซต์อัตโนมัติ |

## เริ่มเรียน

1. เปิดหน้าเว็บไซต์แล้วค้นหาภาษาที่สนใจ
2. อ่านคู่มือและทดลองตัวอย่าง
3. ทำแบบฝึกหัดก่อนเปิดดูแนวคำตอบ
4. เลือกโปรเจกต์เล็ก ๆ มาลองทำ

## ข้อจำกัดที่ควรรู้

Playground บนเว็บไซต์รองรับ JavaScript ฝั่งเบราว์เซอร์เท่านั้น ส่วน API Lab ใช้ข้อมูลจำลองและ Coding Challenge ตรวจรูปแบบคำตอบเบื้องต้น ไม่ได้รัน Python, C, Java หรือภาษาอื่นบนเซิร์ฟเวอร์ และไม่ได้ติดตั้งแพ็กเกจภายนอกให้โดยอัตโนมัติ
