# CyberAtlas TH — ศูนย์เรียนรู้ Cybersecurity ภาษาไทย

คลังเรียนรู้ความปลอดภัยไซเบอร์สำหรับผู้เริ่มต้น อธิบายแบบภาษาคน อ่านง่าย ไม่ต้องทำเป็นรู้ศัพท์เทคนิคทุกคำ เป้าหมายคือเข้าใจความเสี่ยง ป้องกันระบบ และใช้อินเทอร์เน็ตอย่างปลอดภัย

## หัวข้อหลัก
- พื้นฐาน Cybersecurity และเครือข่าย
- DDoS: ความหมาย ผลกระทบ สัญญาณผิดปกติ และแนวทางป้องกัน
- ความปลอดภัยเว็บไซต์และ API
- Phishing และกลโกงออนไลน์
- Malware และการลดความเสี่ยง
- การรับมือเหตุการณ์ไซเบอร์
- รหัสผ่าน MFA และความเป็นส่วนตัว
- พื้นฐานภาษาโปรแกรมและเครื่องมือที่ใช้เรียนรู้ระบบ

## เปิดเว็บไซต์

GitHub Pages จะเผยแพร่จาก branch `main` ผ่าน GitHub Actions ตั้งค่าที่ [Settings → Pages](https://github.com/somegameprojects-studio/ALL-LANGUAGES-PROGRAMMING/settings/pages) โดยเลือก Source เป็น GitHub Actions

## ฟีเจอร์
- Cybersecurity Learning Hub
- คู่มือ DDoS และการป้องกัน
- คู่มือความปลอดภัยเว็บ Phishing Malware และ Privacy
- Code Visualizer และ JavaScript Playground
- API Lab ใช้ข้อมูลจำลอง
- Skill Tree และ Coding Challenge
- คลังคู่มือภาษาโปรแกรมและเครื่องมือ 113 รายการ

## ขอบเขตและความปลอดภัย
เนื้อหาเน้นการเรียนรู้ การป้องกัน และการรับมืออย่างถูกกฎหมาย ไม่สอนโจมตีระบบจริง ขโมยข้อมูล หลบเลี่ยงการตรวจจับ หรือทำให้บริการของผู้อื่นหยุดทำงาน การทดสอบต้องทำบนระบบของตัวเองหรือได้รับอนุญาตอย่างชัดเจน

DDoS ในคู่มือนี้อธิบายระดับแนวคิด ผลกระทบ และการป้องกันเท่านั้น ไม่ใช่คู่มือสร้างทราฟฟิกโจมตี
