# คลังความรู้ภาษาโปรแกรมและเทคโนโลยี

คลังความรู้นี้จัดทำขึ้นเพื่อสอนภาษาโปรแกรมและเครื่องมือทางเทคโนโลยีเป็นภาษาไทย ตั้งแต่ผู้เริ่มต้นที่ยังไม่เคยเขียนโค้ด ไปจนถึงผู้ที่ต้องการต่อยอดทำโปรเจกต์จริง

## เริ่มต้นอย่างไร

1. เลือกภาษาหรือเครื่องมือที่สนใจจากสารบัญ
2. อ่านว่าเครื่องมือนั้นคืออะไร ใช้ทำอะไร และทำงานอย่างไร
3. เตรียมโปรแกรมที่จำเป็นตามคู่มือทางการ
4. ทดลองตัวอย่างด้วยตัวเอง
5. ฝึกแนวคิดพื้นฐาน เช่น ตัวแปร เงื่อนไข การทำซ้ำ และฟังก์ชัน
6. ทำโปรเจกต์เล็ก ๆ แล้วค่อยเพิ่มความยาก

## มีอะไรในคลังนี้

- คู่มืออธิบายแนวคิดและวิธีทำงานของแต่ละภาษา
- ตัวอย่างโค้ดพร้อมคำอธิบายและผลลัพธ์
- บทเรียนจากพื้นฐานไปสู่การใช้งานจริง
- แนวทางฝึกทำโปรเจกต์
- แหล่งเรียนรู้เพิ่มเติม

## วิธีทำงานของโปรแกรมโดยภาพรวม

1. **เขียน:** เราพิมพ์คำสั่งหรือข้อมูลลงในไฟล์
2. **ตรวจ:** เครื่องมืออ่านและตรวจว่ารูปแบบถูกต้องหรือไม่
3. **แปลหรือประมวลผล:** บางภาษาคอมไพล์ก่อน บางภาษาประมวลผลระหว่างทำงาน
4. **ทำงาน:** คอมพิวเตอร์ทำตามคำสั่ง หรือเครื่องมือปลายทางนำข้อมูลไปใช้
5. **แสดงผล:** เราดูผลลัพธ์และแก้ไขเมื่อพบข้อผิดพลาด

ไม่ใช่ทุกอย่างในสารบัญจะเป็นภาษาโปรแกรม เช่น HTML ใช้วางโครงหน้าเว็บ, CSS ใช้ตกแต่ง, SQL ใช้ถามข้อมูลจากฐานข้อมูล และ JSON/YAML ใช้จัดเก็บข้อมูลหรือค่าตั้งค่า หน้าที่ของแต่ละอย่างจึงไม่เหมือนกัน

อ่าน [แนวทางการมีส่วนร่วม](CONTRIBUTING.md) ก่อนเพิ่มตัวอย่างหรือแก้ไขคู่มือ กรุณาใช้ภาษาไทยที่เข้าใจง่าย ตรวจสอบโค้ด และบอกวิธีทดลองให้ชัดเจน
