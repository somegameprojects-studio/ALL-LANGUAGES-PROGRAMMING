# All Languages Programming

An open-source, community-friendly knowledge hub for learning programming languages — from beginner fundamentals to practical projects.

> **Goal:** make programming knowledge easier to discover, understand, practice, and contribute to.

## What you'll find

- **Language guides** — syntax, concepts, standard libraries, and ecosystem notes.
- **Examples** — small, focused, runnable code samples.
- **Tutorials** — step-by-step learning material.
- **Projects** — practical exercises and portfolio-friendly ideas.
- **Resources** — official documentation, tools, and learning references.

## Repository structure

```text
.
├── docs/          # Project documentation and learning paths
├── examples/      # Small, focused code examples
├── languages/     # Language-specific guides and samples
├── projects/      # Practical project ideas and walkthroughs
├── resources/     # Curated official docs and learning links
└── tutorials/     # Step-by-step tutorials
```

## Getting started

1. Choose a language in `languages/`.
2. Read its guide and check the example prerequisites.
3. Run examples using the language's official runtime or compiler.
4. Try a tutorial or build a small project.
5. Verify versions and commands against official documentation.

## Contributing

Contributions are welcome: fix an explanation, add a tested example, write a tutorial, or improve a resource list.

Please read [CONTRIBUTING.md](CONTRIBUTING.md) before opening a pull request.

## Quality principles

- Prefer official documentation as the source of truth.
- Include runtime/compiler versions when they matter.
- Keep examples small, readable, and safe to run.
- Explain expected output and how to execute each example.
- Do not commit secrets, credentials, or personal data.
- Clearly label unverified or experimental content.
