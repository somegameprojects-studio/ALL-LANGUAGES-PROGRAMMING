# ตัวอย่างโค้ดแยกตามภาษา

โฟลเดอร์นี้รวบรวมไฟล์ซอร์สโค้ดตัวอย่างจริง เพื่อให้เปิดดูและทดลองได้

## ตัวอย่างที่มีในตอนนี้

- Python: `python/hello.py`
- JavaScript: `javascript/hello.js`
- TypeScript: `typescript/hello.ts`
- C: `c/hello.c`
- C++: `cpp/hello.cpp`
- Java: `java/Hello.java`
- Go: `go/hello.go`
- Rust: `rust/main.rs`
- Lua: `lua/hello.lua`
- PHP: `php/hello.php`

## ทำไมแถบ Languages อาจไม่แสดงครบทุกชื่อ?

GitHub วิเคราะห์เนื้อหาไฟล์ด้วยระบบ Linguist ไม่ได้อ่านรายชื่อโฟลเดอร์หรือ README เพื่อกำหนดสถิติภาษา ไฟล์ตัวอย่างจริงช่วยให้ระบบตรวจจับได้เมื่อรองรับ แต่ไม่สามารถรับประกันว่าทุกภาษาจะปรากฏในแถบสถิติ เพราะมีการจัดประเภทและเงื่อนไขของ GitHub เอง
